# secretSanta2026
Very simple secret santa picker with 2 draws for 2 different family branches

To use, follow the examples to add a .env file (use a gmail app password, not your master password) and a config.js file with the names and email addresses, exclusions, and gift giving counts

If you want to exclude previous year's picks made before using this script, add them in json format as seen in previousPicks.json.example

then npm i to install the deps and node secretSanta2026.js to run
